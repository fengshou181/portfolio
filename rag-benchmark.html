RAG · TEXT-TO-SQL

电商数仓智能问答系统

基于本地 LLM（Ollama + qwen2.5:3b）与向量检索（Chroma + bge-small-zh）的 Text-to-SQL 系统： 中文自然语言提问，自动检索库表结构、生成并校验 SQL、查询 Apache Doris 数仓（2.75 亿行），返回结果表格。 全链路本地运行，零数据外发。

→

→
4sqlglot 白名单校验
→
5Doris 执行 + 结果直出

结论：准确率仅差 1 题且 7b 的失败为执行错误，本机 CPU 推理下 3b 延迟低 5 倍、内存省一半，定为默认模型；评测集可随时复测新模型。

准确率优化路径（评测驱动）

  • 基线 26.7%：首版知识库仅覆盖 5/25 张表，3b 频繁幻觉不存在字段 → 执行失败
  • 检索改造：知识库扩至全部 25 表（154 条文档）+ 每库示例 SQL + 库路由与宽表保底注入
  • 优化后 86.7%~90%：执行成功率 100%、零重试，P50 降至 1.1s
  • 工程质量：sqlglot 解析树表白名单 + Doris 只读账号 + 提示词防注入，23 个 pytest 用例兜底回归
